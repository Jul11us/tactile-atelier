## 同一种制作思路

- **从材质出发。** 半透明软糖、光亮焦糖、薄玻璃、柔软黏土，用具体的表面特征建立每个场景的性格。
- **让动作有余韵。** 弹簧形变、惯性与逐渐停下的运动，让手指离开后，物件仍然给出回应。
- **给物件留出空间。** 白色舞台、衬线斜体标题、紧凑面板与简短提示，构成系列共用的版式。
- **让源码容易打开。** 一个玩具就是一个 HTML 文件，界面、场景与交互放在一起。

## 本地运行

克隆或下载仓库，在文件夹内打开终端，启动静态服务器：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

打开 **[localhost:8000](http://localhost:8000/)** 浏览玩具集，也可以直接访问 **[jelly-bricks.html](http://localhost:8000/jelly-bricks.html)**。无需安装 npm 依赖，也没有构建步骤。

请使用支持 WebGL 的现代浏览器。玩具页面通过 **unpkg.com** 加载 JavaScript 模块，因此需要联网：大多数场景使用 Three.js **0.160.0**，Crystal Grow 使用 **0.170.0**，需要刚体物理的页面使用 **cannon-es 0.20.0**。各页面内列有对应的鼠标与键盘操作。

## 再做一个

**[tactile-toy Skill](tactile-toy/SKILL.md)** 为 AI 编程助手提供可复用的制作简报、实现流程与参考库：选定材质，写清动作与反馈，从模板开始制作，再到浏览器中检查实际效果。

**两种安装方式：**

1. **安装包：** [下载 tactile-toy.skill](https://github.com/Jul11us/small-games/raw/refs/heads/main/tactile-toy.skill)，在支持 `.skill` 格式的助手中导入。
2. **文件夹：** 将 [`tactile-toy/`](tactile-toy/) 复制到助手配置的 Skills 目录，例如 `~/.codex/skills/tactile-toy/` 或 `~/.claude/skills/tactile-toy/`。

然后，直接描述想做的东西：

> 用 tactile-toy 做一个软糖小玩具：可以捏、拉、堆起来，松手后慢慢回弹，保持这个系列的白底版式。

> Use tactile-toy to make a water-balloon toy: glossy rubber, a heavy stretch when lifted, and a gentle wobble when dropped. Deliver one HTML file.

Skill 的制作说明主要使用中文，示例页面的界面使用英文。

```text
tactile-toy/
├── SKILL.md                 # 制作流程与设计规则
├── assets/
│   └── template.html        # 共用版式与场景基础
├── references/
│   ├── materials.md         # 材质配方
│   ├── feel.md              # 弹簧、形变与交互
│   └── catalog.md           # 14 个内置示例的索引
└── examples/                # 14 份完整 HTML，Nº 09–22
```

仓库根目录是 **17 个可玩的作品**；Skill 内附 **14 个示例**，作为制作时的参考。
