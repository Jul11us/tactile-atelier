The Tactile Toy Skill documents the visual language, interaction patterns, and craft behind this collection, with a template and working examples.

把触感、声音与一点点好奇心，做成一个可以玩的网页。

Read the Skill ↗Download .skill ↓Explore the source ↗

Desktop recommended for the toys. Follow the controls inside each scene; some sounds begin after a click.

The toys load Three.js from unpkg; some also use cannon-es. An internet connection and a WebGL-capable browser are required.

Small things. Time well spent.
